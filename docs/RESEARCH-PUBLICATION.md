# Research publication scope

The private repository contains the PRD, safe source-app UI references, valid gesture/audio experiments and generated test exports. These remain research material and must never be bundled in the product.

The local research folder is more extensive. Git excludes the human-assisted camera photograph/cropper screenshots (041–044), native recipient suggestions (081), unrelated external browser/store/launcher captures, uncontrolled high-line screenshots, invalid runs, raw device UI XML/configuration dumps, recorder logs and failed diagram drafts. The original evidence catalog records these observations without asserting they are available in the cloud checkout.

Some provenance links in the original research documentation point to those intentionally withheld files. Their absence in a cloud checkout is expected and does not justify reconstructing, fabricating or silently claiming to inspect them. The curated gallery's referenced media remain available. The P0 Android implementation does not need the withheld private captures.

Local setup proof screenshots stay outside Git. No credentials or signing keys belong in this repository.
