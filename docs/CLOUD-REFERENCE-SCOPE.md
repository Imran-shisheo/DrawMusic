# Cloud starter reference scope

The initial cloud checkout includes the full PRD, roadmap, toolchain/build scripts and 16 representative screenshots, plus the independently generated source MIDI/WAV/MP4. The complete local research checkpoint (5b507cc) has 146 safe screenshots and additional experiments; a large browser upload was rejected, so the cloud starter deliberately uses the smaller reference set. Missing provenance links are expected. Do not claim to inspect unavailable recordings/screenshots, and never ship source-app reference media.

The owner's complete research remains in the original Mac folder. Clone the remote cloud development repository into a fresh folder for local iOS work, keeping that research checkout intact. Do not force-push the local research main over cloud development.
