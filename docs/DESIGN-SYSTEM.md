# Design system

27 October 2026. Implementation in progress; these decisions guide review and are not executed acceptance evidence.

Use semantic warm light and forest-charcoal dark surfaces. Primary text and action foregrounds must meet 4.5:1 contrast for normal text; measure final token pairs. Keep document paper and instrument colors independent of chrome. Establish heading/body/label/caption roles with a friendly bundled, licensed font and real Japanese, Korean, Hindi, Thai and Vietnamese coverage; never download fonts at runtime.

Spacing follows a 4 dp base, with 12/16/24 dp component and section gaps. Controls retain at least 48 dp interactive targets. Use rounded 16–28 dp surfaces sparingly, clear borders and restrained elevation rather than large blur. Material rounded/outlined icons share optical sizing and visible selected labels/checks. Important actions retain text or accessible names. Large text must wrap or reflow rather than shrink.

One centralized provisional brand definition owns the display name. The original decorative line-to-wave motif belongs to application chrome only. Name-specific launcher assets await the owner's final choice. Keep the native application identifier and existing saved documents unchanged.

Shared sheets use a title, dismiss control, keyboard-safe bounded scrolling content and predictable actions. Phones use bottom sheets; wide windows use bounded panels. Native pickers/share/providers remain native. Focus enters panels and returns on dismissal. All custom transitions respect system and persisted reduced-motion preferences.

Final font sources, licenses, token values, measured contrast and component API are to be recorded with the implemented source and asset provenance.
