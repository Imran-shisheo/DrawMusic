# Bundled offline typography

The UI redesign uses **Nunito Sans** for its friendly open forms and distinct medium/semibold hierarchy. Latin accents and Vietnamese are present in its actual cmap. Script fallback families are **Noto Sans Devanagari** (Hindi), **Noto Sans Thai**, **Noto Sans Arabic** (forced RTL/user-title fixtures) and **Noto Sans CJK** (Japanese/Korean). Their source bytes, licenses, sizes and SHA256 values are recorded in [FONT-MANIFEST.json](FONT-MANIFEST.json).

Nunito Sans was obtained on 27 October 2026 from the official [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/nunitosans) with its SIL Open Font License 1.1. The reviewed variable master was instantiated at 400/500/600/700, width100, optical-size12, YTLC500 using fontTools `instantiateVariableFont(updateFontNames=True)`. These are static font instances, not copied competitor assets or a new product brand. Internal instance names and weights differ correctly. Original copyright and OFL notices remain. The copyright statement specifies no reserved font name. `tool/build_ui_font_instances.py` rejects a different master hash; fontTools is a development-only tool, not a Flutter/runtime dependency.

Noto files are unmodified reviewed installed font-package bytes: fonts-noto-core 20201225-2 and fonts-noto-cjk 1:20240730+repack1-1. Upstream families come from [Noto fonts](https://github.com/notofonts/noto-fonts) and [Noto CJK](https://github.com/notofonts/noto-cjk). Each file's own copyright and SIL OFL1.1 declaration was inspected. Thai/Devanagari/Arabic ship real regular and bold faces. The original CJK collection ships regular outlines with broad Han/Hiragana/Katakana/Hangul coverage; heavier requested UI styles may be synthesized by the renderer. Regional glyph preferences and typography quality remain human review, not proven merely by a codepoint test.

The complete bundle adds approximately **21 MB raw assets**, dominated by the full CJK collection. This preserves native-language/user-title coverage instead of shipping only the small set of current UI glyphs. Actual compressed APK growth is measured by the Android build; this source number is not an APK-size or memory claim. No font is fetched at app runtime, and no font service or Flutter dependency is added.

`AppTypography` centralizes family/fallback names. OFL texts are included in Flutter assets and registered once through `AppTypography.registerLicenses()` for the native Flutter license page. `test/bundled_font_test.dart` independently parses actual OpenType/TTC cmap format4/12 glyph indices and requires every shipped localized UI character plus an Arabic fixture to be present in the bundled stack. Its license-registry test checks notices and idempotence. Glyph presence does not prove correct shaping, line breaks, pronunciation or human-reviewed translation quality.

The BEFORE visual baseline uses explicitly loaded pinned-SDK Roboto and Material Icons; Corrective AFTER captures explicitly load the bundled Space Grotesk/Nunito/Noto faces and remaining Material Icons, with the original Doodimo action glyphs drawn as paths, never flutter_test's Ahem. Real-font compact/large-text screenshots are visually reviewed and kept separate from owned-emulator recordings and physical-device acceptance.

## Corrective display typography

After the owner rejected the first UI composition, Space Grotesk semibold/bold was added as a genuinely different display voice; it does not replace Nunito body text or the non-Latin fallbacks. `AppTypography.displayFamily` and `displayFallbacks` centralize this distinction. Official master/OFL URLs are pinned to Google Fonts commit e7db6ca603fd4862010383ff17ffd6cc4ffac1c0 with source SHA256. The variable master has only a weight axis. Its STAT table does not name weight600, so static instances use explicit unique name/weight/style metadata; the font outlines and original copyright/OFL stay intact. The two faces contain 735 mapped glyphs each, including the sampled Vietnamese tone-letter forms. Non-Latin headings use the bundled fallback stack and require fresh visual/human shaping review. The first rejected iteration is not evidence of this corrective typography or approval of the new design.
