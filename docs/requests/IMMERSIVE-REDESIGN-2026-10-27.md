This supersedes the warm-paper/forest/minimal visual direction, including both preview iterations. Functional, accessibility, data and verification requirements in the original full redesign request remain authoritative.

## 1. Product ambition

Create a premium audiovisual creative world for a Gen Z audience. Design backdrop, lighting, typography, depth, artwork, icons, dock, controls, sheets and transitions as one coherent scene. Beige backgrounds, oversized generic cards, a dark dock attached to the old layout or familiar utility forms do not satisfy this request. Visually rich motion-led interaction must remain easy to understand.

## 2. Palette and materials

Abandon defining warm ivory/forest/sage. Start with ink navy #090B18/#0B1020, layered indigo #151B35, electric violet #8B5CF6, luminous cyan #55DFF5 and restrained pink accents. Measure contrast rather than assuming these combinations pass. Use one consistent gradient family, large low-frequency auroras, localized bloom, controlled luminous edges and selective layered translucent surfaces. Keep off-white text crisp and secondary labels legible. Build an intentional cool luminous light theme, not beige or a simple inversion. Document paper, instrument colors and saved artwork are independent of chrome.

## 3. Prominent real motion graphics

Implement a bounded original ribbon/ink-to-sound sculpture on Home: depth-layered curves, slow gradient motion, controlled traveling highlights and restrained orbital accents. The app must visibly live in an actual emulator recording; a static logo or PNG cannot prove this. Artwork movement uses real project/template paths or clearly decorative original art, never fake activity/meters. Orchestrate a short scene reveal; provide tactile presses, coordinated selection/directional navigation and depth-aware sheets. Keep text and targets stable. Stop offscreen/hidden/background tickers and decorative movement under reduced motion. Freeze/reduce distracting editor decoration. Only actual audio status/clock may drive sound-reactive visuals; no independent beat scheduler or fake live waveform.

## 4. Replace rejected iconography

Replace every rejected thin handmade glyph with a polished coherent original duotone/soft-dimensional family: rounded filled planes, precise foreground geometry, tasteful highlights/material accents, consistent optical weight at 24/28/32 dp. Main navigation, Create, voices and export types need recognizable silhouettes, selected/unselected/disabled/pressed states and labels. Utilities such as Back/Close remain familiar and precise. Do not mix random stock symbols with unrelated drawing styles. Inspect actual raster output at UI and launcher sizes. The original Doodimo launcher mark must share the new ribbon/sound identity; do not retain the rejected generic loop/note merely because it is original.

## 5. Immersive Home scene

Anchor the opening viewport with the original animated audiovisual sculpture and a real artwork preview. Use a strong brand lockup, short expressive headline and intentional hierarchy. Create/Start Drawing should feel like activating an instrument, integrated in the scene rather than an ordinary filled button. Continue/recent work must come from actual saved data. Templates are rich artwork windows with depth, tonal framing, titles and responsive press feedback. No fake recommendations/statistics/streaks, generic marketing card, sparse giant headline or decoration that obscures the next action.

## 6. Signature navigation

Build a compact floating glass/ink capsule with a controlled luminous edge, duotone destination icons and a distinctive Create key. Selected icon/label and coordinated moving indicator must be clear; do not recolor the existing rectangular dock. Keep Home/Library/Settings readily available. Preserve branch navigators, scroll, dialogs, focus, pending language, editor origin/controllers/audio lifetimes. Safe-area and scroll insets must prevent covering labels. At 320 dp/200% text adapt the structure, including an accessible rail/sheet arrangement if useful; do not shrink labels/targets or fragment long words.

## 7. Immersive editor instrument

Keep the canvas dominant and its document rendering unchanged. Surround it with coherent focused chrome: project identity, honest save state, labeled Export; a deliberate icon tool palette for Draw/Erase with clear selection; logical Undo/Redo. Integrate a distinctive Play/Pause key, named instrument artwork/chooser, readable BPM/root/scale and progressive advanced tools. All thirteen voices remain accessible with actual names, color linkage and selected check. Build original rich filled/duotone voice visuals, not the rejected thin sketches. Cursor/active-note response follows actual audio. Never animate canvas size during a gesture, remount project/audio ownership, reset live ink or delay pointer/play response for decoration.

## 8. Export and secondary surfaces

Use dimensional format objects or a refined connected Image/Sound/Video/Notes selector, labels/abbreviations, a prominent frozen real preview and focused relevant controls. Replace pastel cards/questionnaires. Transition selection/preparation/actual progress/finalization/ready/error/cancel truthfully. Keep Cancel and export owner intact, success only after publication, and Share/Save/Open actual artifact actions; opening a share sheet is not delivery.

Carry the SAME materials/type/icons/lighting/motion into paper/crop, voice/music panels, Library, Settings, onboarding/help, empty/recovery/error/rating states. Library should feel like a creative gallery; Settings can be restrained but branded. Do not revert to generic AlertDialog/ListTile/outlined-card arrangements or decorate every surface. Preserve all existing transactions, crop geometry, recovery and file actions.

## 9. Typography and optical polish

Keep bundled licensed distinctive display and legible UI fonts with deliberate hierarchy/tracking/line height, correct fallbacks for all twelve locales, Hindi/CJK/Thai and forced RTL/user titles. Avoid tiny uppercase captions and illegible low-opacity gray. Establish consistent spacing, corners, shadows and border weight. Judge zoomed pixels and actual interaction, not source declarations.

## 10. Functional, accessibility and operating invariants

Preserve ALL PR22 fixes, project/recovery formats, offline behavior, synthesis/audio/session timing and PNG/WAV/MIDI/MP4 correctness. Separate repaints, cache bounded vector geometry, stop hidden tickers and profile actual UI/raster timing. No particle storm, uncontrolled full-screen blur, full-scene rebuild per tick or battery-heavy loops. Touch targets >=48 dp and normal text contrast >=4.5:1 where applicable; non-color selection, stable focus/semantics, keyboards/safe areas, 200% reflow and tablets/landscape remain required. Reduced motion renders a designed static luminous composition with clear state changes and no decorative loops/large travel.

All creative features free; no ads/accounts/billing/remote assets/services/uploads/paid infrastructure. No owner-phone operation, merge, force push, store publication or scheduled continuation. Android cloud is executable; Mac/iOS/physical acceptance cannot be claimed from Linux.
