# More apps — next-build feature, 2 November 2026

Settings → Help and app information now includes **More apps**, with a labelled external-store hint and the existing graphite glyph/touch-target treatment. Android opens `https://play.google.com/store/apps/developer?id=DevWithDelta`; iOS opens `https://apps.apple.com/developer/imran-khan/id6773044710`. The coordinator independently verified both in a real browser: the Android developer anchor leads to DevWithDelta's apps, and the region-neutral Apple URL redirects to the regional Imran Khan developer page, ID6773044710. These are public storefronts, never account/Console URLs. Store localization/installed-app routing remains OS-owned.

The existing external-application launcher is shared with Privacy Policy without adding a dependency. Privacy URL/labels/failure behavior remain intact. A launch only follows an explicit user action; no page is fetched or embedded in the app. Each action suppresses repeat callbacks while opening, restores the row after a false result/exception and presents a localized, generic retry message. It safely tolerates leaving/disposal during completion. Missing/invalid configuration and unsupported platforms omit the row rather than send users to a wrong store. Normal labels wrap, preserve 48dp minimum targets and use existing theme/semantics. All12catalogs contain379matched keys.

This branch starts from PR25 head `be7e42de83050934fb0794b71945d1e17af6662e` and is a separate stacked draft change. The production version24 binary currently under Google review is immutable for this task: no AAB is rebuilt/re-signed/uploaded, no store review or release/version metadata is changed, and no signing key is accessed. The local debug APK is solely a next-build test artifact. A future owner-authorized release must assign an appropriate new version code; this feature does not silently do so.
