# P0 implementation and acceptance coverage

Updated 25 October 2026. This maps the completed PRD to the current Android branch. Cloud evidence and physical acceptance are different gates. No row closes physical acceptance from a fake audio adapter, a setup-only build or the owner's report about an earlier build. Pixel style is F11/P1 in the PRD; it is an implemented optional addition, not a missing P0 prerequisite.

| PRD requirement | Current implementation and evidence | Remaining acceptance or limit |
|---|---|---|
| F01 entry/help | Offline first-use guide, skippable contextual tips, persisted completion, replay, blocked tap-through and failed-write retry. Settings/tip widgets and full Android restart flow pass. | Physical focus return/TalkBack and suspension mid-tip. |
| F02 templates/navigation | Original template copies, New, retained Home/Drafts/Exports/Settings branches, scroll/section memory and guarded editor/modal Back. Navigation/widget/native UI checks pass. | Full device layout and accessibility review. |
| F03 drawing/input | One active pointer, normalized immutable commits, round lines/dots, cancel/leave finishing, active-gesture refresh reliability and a 10k-pointer/100k-project test. Current tool-switch guards commit active ink/erasure before changing voice or mode; the multi-pointer regression preserves assignments and Undo. | At 100k points, the app finishes the valid stroke and explicitly asks for Save/New; it preserves all points instead of automatically simplifying older geometry. Device stylus/long-session performance remains open. |
| F04 instruments | Three named original synthesized voices, distinct icons/colors and selected chips. Geometry/score/PCM/export checks preserve assignments. | Original synthesis replaces the proposed sample-set implementation. Physical timbre/feedback acceptance; no locked catalog ships. |

Optional F11 Pixel display is implemented and cloud-verified without changing editable geometry or music. F12 accompaniment/mixing, F16 PNG, expanded catalogs, photos/camera/cropping, secondary translations, premium/entitlements and optional ads/rating remain deferred. No backend, account, paid service, store publication or automatic rating/purchase is introduced.
