# Localization and language selection

The creative-expansion build ships twelve locales: English, French, Spanish, Italian, Korean, Japanese, Vietnamese, Hindi, Portuguese, Thai, Filipino/Tagalog and Indonesian. See [translation scope and review status](TRANSLATIONS.md). Newly authored translations are implemented; native-speaker linguistic review remains pending.

Settings → Language shows native names in a scrollable list with an explicit selected indicator. Choosing a row stages a pending selection. Apply persists it before returning; Cancel or Back discard it. Failed writes stay retryable. Unsupported/missing saved codes fall back to English without discarding unrelated preferences or drawing data. The router is retained across locale rebuilds so root tabs and loaded page state survive. Applying a language does not create a musical revision or modify a project.

Interface resources live in all twelve `lib/l10n/app_*.arb` files. Generated committed classes under `lib/l10n/generated` provide each resource explicitly. Material/Cupertino/widget delegates handle system widgets. `context.strings` supplies English only for isolated reusable hosts without app delegates; production app routes install the selected locale. No missing operational key is deliberately delegated to English. Standard formats, acronyms, musical-mode loanwords and the product name can legitimately match between languages.

Resources cover navigation, editor/transport/style/backgrounds, instrument and scale choices, accompaniment, tips, help, settings, rating consent, names and export/library operations, including typed error and recovery guidance. Dynamic score/draft summaries accept the actual root and full scale name rather than embedding C pentatonic. The native Android exported-file chooser title is translated too. iOS camera-purpose strings are included as uncompiled source. Internal native errors are mapped to localized guidance instead of displaying exception messages.

User titles, original template/default document titles, project IDs, geometry, score values, checksums and standard MIDI/WAV/MP4/PNG bytes are never translated. Display helpers format numbers and UTC timestamps in the active locale/local time; storage and file-format numbers remain invariant.

After changing English messages or placeholders, update every shipped ARB, run `flutter gen-l10n`, formatter and the product check. `test/translations_test.dart` enforces key and placeholder parity, localized operational messages, supported-language persistence, native prompt resources and compact 200% text Apply for all twelve languages. `test/localization_test.dart` covers unsupported/missing recovery through real files, staged Japanese selection followed by Cancel without writes, Apply, failed-save retry, retained root navigation, Unicode project data, English formatting and RTL selector layout. RTL coverage does not imply an RTL translation is shipped. Physical TalkBack/VoiceOver, pronunciation, system permission dialogs and full device acceptance remain pending.
